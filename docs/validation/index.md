## How to read this

- **Reference class.** *analytic*: an exact formula or a construction with a known answer. *published*: a value from a cited paper, book or standard. *cross-solver*: another solver or reader of the same problem. *measured*: a physical measurement (none yet). *self-computed*: the reference was produced by this project's own code (regression locks, report values never recomputed independently). Self-computed cases are shown for regression only and are **never counted as independent validation**; the last column of the table counts passes with an independent reference only.
- **Status.** *pass* and *FAIL* are against the tolerance stated in the row. *known gap* is a documented shortfall (see `docs/FOLLOWUPS.md`) and does not count as passed. *[verify]* means the citation could not be checked; the case is shown but excluded from every pass count. *pending* and *skipped* cases were not run (for example Palace: pending WP-301).
- **Independent.** `no` means the reference shares code, or a network model, with the implementation under test.
