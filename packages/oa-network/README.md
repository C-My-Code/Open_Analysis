# oa-network

S-parameter quality gate and network tools (WP-106).

Public API: `assess`, `make_dc`, `enforce_passivity` (scikit-rf vector fitting), `gate` (interfaces.md
section 4.5), `se2gmm` (ports ordered `+1,-1,+2,-2,...`; output `d1..dp,c1..cp`), `renormalize`,
`shift_reference_plane`. `QualityCriteria` / `QualityReport` live in `oa_results.quality` and are
re-exported.

The PQM/RQM/CQM metrics are implemented independently from the standard's definitions, not ported
from the IEEE 370 reference code (license unverified); CQM is implementation-defined. See
`docs/change-requests/WP-106-ieee370-and-cqm.md`.

Golden suite: `tests/golden/network_quality/` (Touchstone fixtures regenerated by
`packages/oa-network/tests/make_fixtures.py`).
